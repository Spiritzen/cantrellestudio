==================================================
1. OBJECTIF UNIQUE
==================================================

Ajouter un effet de carte 3D interactif autour du visuel PROJET existant,
SANS modifier l’animation des particules déjà validée.

L’ensemble suivant doit bouger comme UN SEUL objet :
- puce-projet.png
- SVG superposé
- toutes les particules animées

Le mouvement hover ne doit jamais désynchroniser l’image, les paths et les particules.

==================================================
2. STYLE VISUEL
==================================================

Créer une enveloppe propre autour du visuel PROJET :

- border-radius sobre : environ 18px à 24px
- overflow hidden si nécessaire pour garantir les coins arrondis
- léger contour Ember / cuivre si cohérent
- box-shadow orange/Ember premium
- glow maîtrisé
- aucune bordure dorée fantasy
- aucun effet HeliFan violet/or
- aucune nouvelle palette

Utiliser les tokens Cantrelle Studio existants autant que possible :
- graphite
- Ember
- accent-soft si pertinent

Le halo doit rester subtil :
pas d’effet néon agressif,
pas de grosse pulsation permanente,
pas de « carte gaming ».

==================================================
3. HOVER 3D
==================================================

Sur desktop / périphérique avec pointeur précis :

Au `pointermove` / `mousemove` dans la zone :
- calculer X et Y relativement au centre du composant
- normaliser entre -1 et 1
- appliquer la rotation sur le wrapper GLOBAL du visuel

Valeurs initiales souhaitées :
- rotateY max : ±8deg
- rotateX max : ±8deg
- scale hover : 1.025

Exemple conceptuel :
rotateY = x * 8deg
rotateX = y * -8deg

Le mouvement doit :
- être fluide
- suivre naturellement la souris
- rester premium
- ne pas donner le mal de mer
- ne pas être brutal

Perspective recommandée :
environ 1000px à 1200px.

==================================================
4. RETOUR AU REPOS
==================================================

Quand le pointeur quitte la zone :
retourner progressivement vers :

rotateX(0deg)
rotateY(0deg)
scale(1)

Transition de retour recommandée :
environ 0.5s à 0.65s
avec easing doux proche de :
cubic-bezier(0.25, 0.46, 0.45, 0.94)

Pendant le suivi direct de la souris :
transition très courte / quasi directe,
pour éviter une sensation de retard.

==================================================
5. GLOW DYNAMIQUE — OPTION LÉGÈRE
==================================================

Si l’implémentation reste simple et propre,
faire légèrement réagir le glow selon la position du pointeur,
comme HeliFan utilise `--px` / `--py`.

Mais rester TRÈS subtil.

Cette partie est secondaire.
Ne pas la faire si elle complexifie ou dégrade le rendu.

Le hover 3D est prioritaire.

==================================================
7. RESPONSIVE / TOUCH
==================================================

Sur mobile / tactile :
- ne pas forcer le tilt permanent
- conserver le visuel fixe
- conserver l’animation des particules existante si elle est déjà prévue ainsi
- pas de comportement étrange au touchmove

Utiliser si nécessaire :
`@media (hover: hover) and (pointer: fine)`

ou détection équivalente propre.

==================================================
8. PREFERS-REDUCED-MOTION
==================================================

Si :
`prefers-reduced-motion: reduce`

Alors :
- désactiver le tilt interactif
- désactiver le scale hover lié au tilt
- retour état fixe neutre

Ne pas casser le comportement reduced-motion existant des particules.
